# Prêts Partez

Web app iPhone qui affiche, en un coup d'œil, quand partir pour attraper son bus en Île-de-France (données temps réel Île-de-France Mobilités).

## Installer sur iPhone

1. Ouvrir le site dans **Safari**.
2. Bouton **Partager** → **Sur l'écran d'accueil**.
3. Ouvrir l'app, toucher ⚙︎ et coller sa clé API gratuite [PRIM](https://prim.iledefrance-mobilites.fr) (« Mes jetons d'authentification »).
4. Ajouter son lieu (🏠 Maison) puis créer un trajet.

La clé API, les lieux et les trajets restent uniquement sur le téléphone (stockage local du navigateur).
